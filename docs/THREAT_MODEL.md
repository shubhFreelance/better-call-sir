# Initial threat model

Synthetic development only; review required before pilot.

| Boundary | Threat | Current control / remaining work |
| --- | --- | --- |
| Browser → API | Forged roles, cross-family IDs, cookie CSRF | Strict input allowlists, server session roles, resource ownership, exact Origin plus CSRF, no-store private responses; explicit endpoint probes |
| Session rotation | Refresh replay, student inherits parent | Hashed opaque credentials; 10-minute access capped by a fixed 30-day family expiry; atomic rotation/insertion, family lock shared with replay/logout, CSRF before replay revocation; replay revokes every generation; separate student principal, guardian consent recheck; staff TOTP with replay-safe recovery and recent-auth/idle/absolute/step-up limits implemented; independent staff access/recovery, epoch-bound sessions and serialized MFA mutations implemented; managed-secret custody, human recovery drills and provider qualification pending |
| Child processing | Unverified parent, withdrawn consent, inappropriate collection | Adult fixture verification plus versioned consent required; minimized alias/class/board; withdrawal serializes with child writes and revokes student access; legal purpose/retention review pending |
| Booking calendar | Double holds and non-equal overlapping intervals | PostgreSQL half-open exclusion across active reservations; held-slot expiration; late capture cannot displace newer reservation; real concurrent tests |
| Money | Forged browser success, duplicate capture, improper refund/payout | Exact-amount checkout, signed raw Razorpay captures, uniqueness/idempotency, captured-order recovery and separate pending refund records; browser callbacks never prove capture; refund/payout settlement, periodic reconciliation and real provider qualification remain open; production blocked |
| Parent notes | All-candidate access, HTML/script injection | Text rendering; sharing restricted to explicit active teacher; revocation and withdrawal; no AI processing/export |
| Pro consultations | Unrelated teacher, overspent allowance, failed call charges | Active assignment/teacher/consent/entitlement checks; serialized allowance reservation, shared calendar, replay-safe synthetic outcomes; actual provider evidence and lifecycle pending |
| Console | Self-approval, audit deletion, unsafe overrides | Role gate, screening prerequisite, reason and confirmation for flags, immutable audit trigger; delegated role/region checks implemented; server MFA/recent-auth and browser private-query gating implemented; independent two-person staff access/recovery and key rotation implemented; versioned independent hiring fee/coverage approval and immutable rollback history implemented; production key/recovery, commercial policy/supply and image qualification pending |
| Worker | Duplicate delivery or crash acknowledges unfinished money jobs | Committed outbox with row locks and SKIP LOCKED; transaction-bound synthetic delivery; refund jobs remain pending; actual external delivery needs provider idempotency/reconciliation |
| Supply chain | Compromised packages/binary trust | Exact lockfile, checksum-verified Prisma engines, pinned PostgreSQL image, production dependency audit; source secrets scanning with redacted findings and full runtime/tooling audits enabled; SAST/SBOM/container/DAST and independent review pending |
